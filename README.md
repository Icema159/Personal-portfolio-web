# Personal Portfolio Page

Personal developer portfolio for Aismantas Skinulis, built as a one-page React website. The page presents my developer profile, current tech stack, selected projects, CV and contact links.

## Tech Stack

- React 19
- Vite / rolldown-vite
- Tailwind CSS 4
- JavaScript
- lucide-react
- framer-motion
- ShaderGradient / React Three Fiber
- GitHub Pages deployment

## Features

- Dark futuristic portfolio design with emerald accents
- Animated star background and subtle grain texture
- Responsive navigation with mobile menu
- Hero section with CV, GitHub, projects and contact actions
- About section with grouped skills and developer focus areas
- Projects section with live links, GitHub links, status badges and tech tags
- Contact section with email, CV, GitHub and LinkedIn links

## Getting Started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Deploy to GitHub Pages:

```bash
npm run deploy
```

Live site:

```text
https://icema159.github.io/Personal-portfolio-page/
```
