This portfolio uses or draws visual/technical inspiration from the following open-source projects:

- [ShaderGradient](https://github.com/ruucm/shadergradient), by ruucm and stone-skipper. The `@shadergradient/react` package is used for the animated background.
- [React Three Fiber](https://github.com/pmndrs/react-three-fiber), by Poimandres. It powers ShaderGradient's Three.js rendering layer.
- [Liquid Glass JS](https://github.com/dashersw/liquid-glass-js), by Armagan Amcalar. The navigation and selected controls use an original CSS implementation inspired by its layered glass treatment; no source code was copied.
- [Liquid Logo](https://github.com/collidingScopes/liquid-logo), by Alan Ang. The initials mark is an original CSS implementation inspired by its liquid-metal aesthetic; no shader source code was copied.
